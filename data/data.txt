RAG (Retrieval Augmented Generation) - это подход в обработке естественного языка (NLP),
который объединяет мощь предварительно обученных языковых моделей (LLM) с возможностью
поиска и извлечения информации из обширной базы знаний. Вместо того чтобы полагаться
исключительно на знания, заложенные в LLM во время обучения, RAG позволяет модели
динамически запрашивать внешние источники данных для получения актуальной и точной
информации, прежде чем генерировать ответ.

Это особенно полезно для уменьшения "галлюцинаций" LLM, обеспечения ответов на вопросы
о специфических или новых данных, а также для предоставления ответов с высокой степенью
актуальности и достоверности, поскольку модель может ссылаться на найденные документы.
FAISS (Facebook AI Similarity Search) - это библиотека для эффективного поиска сходства
и кластеризации плотных векторов. Она позволяет быстро искать ближайших соседей в
больших наборах векторов. FAISS используется в RAG-системах для ускорения поиска
релевантных документов по векторизованному запросу.

FastAPI - это современный, быстрый (высокопроизводительный) веб-фреймворк для
создания API на Python 3.7+ на основе стандартных аннотаций типов Python. Он
очень прост в использовании, обладает автоматической документацией (Swagger UI
и ReDoc) и построен на Starlette для веб-частей и Pydantic для обработки данных.

LangChain - это фреймворк для разработки приложений на основе больших языковых
моделей (LLM). Он упрощает процесс создания сложных цепочек LLM, включая RAG,
агентов и другие приложения. LangChain предоставляет модульные компоненты и
интерфейсы для взаимодействия с различными LLM, базами данных векторов,
инструментами и агентами.
